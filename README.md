# Security Headers Checker

A simple Python tool that checks whether a website has important security headers configured.

## Features
- Checks for common security headers
- Displays which headers are present or missing
- Provides a basic security overview of the target website

## Headers checked
- Content-Security-Policy (CSP)
- Strict-Transport-Security (HSTS)
- X-Frame-Options
- X-Content-Type-Options
- Referrer-Policy
- Permissions-Policy

## How to use
1. Run the script:
2. Enter the website URL when prompted (example: https://example.com)
3. View the results

## Requirements
1. Python 3.x
2. requests library
Install the required library with:
Bashpip install requests
